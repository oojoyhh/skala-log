비밀번호 검증 Mermaid.js 샘플

대문자, 소문자, 숫자, 특수문자 포함 여부를 검증하는 흐름을 시각화했습니다.

flowchart TD S([비밀번호 입력]) --> A{대문자 포함?} A -- 아니오 --> F1[실패] A -- 예 --> B{소문자 포함?} B -- 아니오 --> F1 B -- 예 --> C{숫자 포함?} C -- 아니오 --> F1 C -- 예 --> D{특수문자 포함?} D -- 아니오 --> F1 D -- 예 --> P[검증 통과] P --> E[비밀번호 사용 가능] F1 --> R[조건 미충족]
통과 조건 대문자, 소문자, 숫자, 특수문자를 모두 포함해야 합니다.
실패 조건 하나라도 빠지면 즉시 검증 실패로 처리합니다.
